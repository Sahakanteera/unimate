# UniMate ส่วนที่ 2 — สไลด์ทางเลือก 2 เวอร์ชัน (กลุ่ม AI04)

ชุดเดิม (Creative Mode, HTML) ยังอยู่ที่ `docs/presentation-part2/` และไม่ได้ถูกแก้ไข ชุดในโฟลเดอร์นี้ใช้ข้อเท็จจริงชุดเดียวกัน ได้แก่ สมาชิก ฟังก์ชัน ขอบเขต ผลทดสอบ 52 กรณี / 216 assertions ภาคผนวก 42 หน้า และลำดับเดโม 7 ขั้น

ภาพเปรียบเทียบอยู่ที่ `previews/compare-versions.png` ส่วนภาพรวมทุกหน้าของแต่ละชุดอยู่ที่ `previews/v1-all-slides.png` และ `previews/v2-all-slides.png`

## เวอร์ชัน 1 — ชี้อธิบาย (`v1-callout/`)

- สไลด์พูด 23 หัวข้อ (71 หน้าเมื่อแตกการชี้ทีละจุด) ใช้ภาพหน้าจอจริงเป็นภาพหลัก
- จุดสำคัญใช้ลูกศรสีส้มชี้จากคำอธิบายที่มีเลขกำกับด้านขวาไปที่จุดนั้นโดยตรง ไม่มีกรอบวงหรือเลขบนภาพ เลขเรียงจากบนลงล่างตามแนวสายตา
- หน้าแรกไม่มีการชี้หรือป้ายใด ๆ: ชื่อโครงงานและสมาชิกด้านซ้าย ภาพหน้าจอคอมพิวเตอร์และมือถือด้านขวา
- หน้าที่ชี้อธิบายทำเป็นลำดับ: หน้าแรกของหัวข้อเป็นภาพสะอาดยังไม่ชี้ แล้วหน้าถัดไปชี้ทีละจุด (จุดปัจจุบันสีส้มมีลูกศร จุดก่อนหน้าเหลือเป็นป้ายสีเทา) จึงมีทั้งหมด 71 หน้า กด → ทีละครั้งระหว่างพูด
- การ์ดกิจกรรมมีหน้าแยกที่ซูมการ์ดหนึ่งใบ ชี้ 7 ส่วนทีละจุด (ภาพ 3x ใน `kit/captures/d-card.jpg`)
- เลขหน้าและการอ้างอิง “สไลด์ N” คำนวณใหม่อัตโนมัติตอนสร้างไฟล์
- หน้าที่ภาพเต็มอ่านยาก ใช้การครอปเฉพาะส่วน
- มีแผนภาพเพิ่ม ได้แก่ ภาพรวมการใช้งานแบบแบ่งช่องตามผู้ใช้ สถานะของคำขอ เส้นทางคำขอใน Laravel และความสัมพันธ์ของตาราง
- ฟอนต์: Mitr (หัวเรื่อง) และ Sarabun (เนื้อหา)

## เวอร์ชัน 2 — Studio (`v2-studio/`)

- สไลด์พูด 20 หน้า อิงเทมเพลต studio ในคลังของ frontend-slides
- สีดำสลับเหลือง หัวเรื่องตัวใหญ่ ข้อมูลกำกับใช้ตัวอักษร mono ไม่มีกล่องหรือมุมมน
- เล่าเรื่องผ่านผู้ใช้หนึ่งคน (บัญชีทดสอบ Narin) ใน 6 ขั้น ด้วยภาพหน้าจอมือถือจริง แล้วสลับไปมุมผู้ดูแลระบบ
- ฟอนต์: Prompt (หัวเรื่อง), IBM Plex Sans Thai (เนื้อหา) และ IBM Plex Mono (ตัวเลขและข้อมูลกำกับภาษาอังกฤษ)

## การแก้ไขร่วมกันใน Canva

- ทุกชิ้นในสไลด์เป็นวัตถุแยกกัน และตั้งชื่อเป็นภาษาไทย เช่น `เส้นชี้ 2`, `เลข 2`, `หัวข้อ 2`, `คำอธิบาย 2`, `ภาพหน้าจอ …` จึงย้ายหรือแก้ทีละชิ้นได้
- ภาพหน้าจอเป็นรูปภาพแยกจากคำอธิบาย
- ข้อความเป็นกล่องข้อความจริง และตั้งฟอนต์ไว้ทั้งช่องภาษาอังกฤษและช่องภาษาไทย
- ฟอนต์ประจำธีมของไฟล์ตั้งเป็นฟอนต์เดียวกัน ข้อความใหม่ที่เพิ่มทีหลังจึงได้ฟอนต์ตรงกัน
- ไฟล์ฟอนต์ทั้งหมดพร้อมใบอนุญาต OFL อยู่ที่ `kit/fonts/` ถ้า Canva หาฟอนต์ไม่เจอ อัปโหลดจากโฟลเดอร์นี้ได้ (Canva Pro / ทีม)
- ขนาดสไลด์ 13.333 × 7.5 นิ้ว (16:9)

## สร้างไฟล์ใหม่หลังแก้เนื้อหา

ต้องมี Python ที่ติดตั้ง `python-pptx`, `pymupdf`, `Pillow`, `fontTools`, LibreOffice และฟอนต์ใน `kit/fonts/` (ติดตั้งแบบเฉพาะผู้ใช้ไว้แล้วในเครื่องนี้)

```powershell
cd docs\presentation-part2-alt\v1-callout; python -I -X utf8 build_v1.py
```

```powershell
python -I -X utf8 ..\kit\check.py UniMate-Part2-V1-Slides.pptx
```

```powershell
python -I -X utf8 ..\kit\merge_pdf.py . UniMate-Part2-V1 "UniMate ส่วนที่ 2 — เวอร์ชัน 1"
```

`check.py` แปลง PPTX เป็น PDF ด้วย LibreOffice แล้วตรวจว่ามีข้อความหลุดกรอบหรือมีฟอนต์สำรองหรือไม่ เวอร์ชัน 2 ใช้คำสั่งเดียวกันใน `v2-studio` แต่เปลี่ยน `V1` เป็น `V2`

ภาพหน้าจอความละเอียด 2x/3x และพิกัดจุดที่ชี้อยู่ที่ `kit/captures/` (`boxes.json`) ทั้งหมดถ่ายจากเว็บจริงบนสำเนาฐานข้อมูลตัวอย่าง ฐานข้อมูลของโปรเจกต์ไม่ถูกแก้ไข

## ผลตรวจ และสิ่งที่ยังไม่ได้ทดสอบ

ตรวจแล้ว:
- เรนเดอร์ทั้ง 4 ไฟล์ด้วย LibreOffice (128 หน้า) ไม่พบข้อความหลุดกรอบ
- ใช้เฉพาะฟอนต์ที่ตั้งไว้ ไม่มีส่วนไหนตกไปใช้ Tahoma หรือฟอนต์ระบบ
- ตรวจด้วยตาทุกหน้า และซูมดูวรรณยุกต์กับข้อความเล็กแล้ว
- ไฟล์ผ่าน `validate.py` ของสกิล pptx

ยังไม่ได้ทดสอบ:
- **การนำเข้า Canva** โดยเฉพาะว่า Canva แสดงเส้นชี้ ลูกศร และมุมมนครบหรือไม่ และ Canva มีฟอนต์ Mitr, Sarabun, Prompt, IBM Plex Sans Thai ในคลังหรือไม่ ถ้าไม่มี Canva จะแทนด้วยฟอนต์อื่น ระยะบรรทัดและการตัดคำอาจเปลี่ยน
- **การเปิดใน Microsoft PowerPoint** เพราะเครื่องนี้ไม่มี PowerPoint ผลที่ตรวจได้มาจาก LibreOffice เท่านั้น
