03 — ผู้ใช้งานRoles

Guest

  • สมัครสมาชิกนักศึกษา
  • เข้าสู่ระบบ
  • บัญชีที่ถูกระงับเข้าระบบไม่ได้
Student

นักศึกษา

  • ค้นหา ขอเข้าร่วม ติดตามนัดของฉัน

04 — ขอบเขตระบบScope
ขอบเขตระบบ

ทำอะไรได้ และไม่ได้ทำอะไร

อยู่ในขอบเขตIn scope

  • บัญชี 2 บทบาท (นักศึกษา / ผู้ดูแลระบบ) และการระงับบัญชี
  • โพสต์กิจกรรม: สร้าง แก้ไข ยกเลิก ค้นหา กรอง
  • คำขอเข้าร่วม อนุมัติ / ปฏิเสธ จำกัดตามจำนวนที่รับ
  • เช็กชื่อ นัดของฉัน และการแจ้งเตือนภายในเว็บ
  • รีวิวหลังจบกิจกรรม รายงานปัญหา และการตรวจของผู้ดูแล
  • ใช้งานผ่านเว็บเบราว์เซอร์ ทั้งคอมพิวเตอร์และมือถือ

ไม่อยู่ในขอบเขตOut

  • ซื้อขายสินค้าและชำระเงิน (ข้อห้ามของวิชา)
  • แชตระหว่างผู้ใช้
  • แจ้งเตือนทางอีเมลหรือพุช
  • อัปโหลดรูปกิจกรรม และแผนที่
  • เชื่อมบัญชีมหาวิทยาลัย / แอปมือถือ

04 — ขอบเขตระบบRules
กฎที่ระบบบังคับใช้

ตรวจที่เซิร์ฟเวอร์ ไม่ใช่แค่ซ่อนปุ่ม

กฎผลลัพธ์เมื่อฝ่าฝืน / กลไก
แก้ไขหรือยกเลิกโพสต์ได้เฉพาะเจ้าของผู้อื่น (รวม Admin) ได้ 403 · ActivityPolicy
กิจกรรมที่ยกเลิกแล้วแก้ไขต่อไม่ได้ได้ 409
ขอเข้าร่วมได้เมื่อยังไม่เริ่ม ไม่ใช่โพสต์ตัวเอง ไม่ถูกซ่อน และยังไม่เต็มปุ่มไม่แสดง และเซิร์ฟเวอร์ปฏิเสธ
อนุมัติเกินจำนวนที่รับไม่ได้ แม้กดพร้อมกันDB transaction + lockForUpdate
เช็กชื่อได้เฉพาะผู้ที่อนุมัติแล้วแจ้งข้อผิดพลาด ไม่บันทึก
รีวิวได้ครั้งเดียว หลังกิจกรรมจบ และต้องถูกเช็กชื่อว่า “มา”แจ้งเหตุผล · unique (activity, user)
รายงานตัวเองไม่ได้ และรายงานซ้ำระหว่างรอตรวจไม่ได้แจ้งข้อผิดพลาด
บัญชีที่ถูกระงับเข้าสู่ระบบไม่ได้ถูกออกจากระบบ · Middleware active

05 — เทคโนโลยีLaravel
โครงสร้างระบบ

หนึ่งคำขอ ผ่าน Laravel อย่างไร

หน้าเว็บBlade layout + components · Tailwind CSS · JavaScript (toast, เปิด-ปิดรหัสผ่าน, ย่อรูปโปรไฟล์ด้วย Canvas)
RoutesResource routes · Middleware auth · active · admin · CSRF ทุกฟอร์ม
ControllersForm Request validation · Policy / Gate ตรวจเจ้าของ · Notifications
ModelsEloquent: belongsTo / hasMany · casts วันเวลา · helper เช่น isFull(), reviewBlockReason()
DatabaseSQLite ผ่าน migrations + seeders · เปลี่ยนเป็น MySQL ได้จาก .env

นำสิ่งที่เรียนมาใช้

  • HTML / CSS: โครงหน้า ฟอร์ม และ layout ที่รองรับมือถือ
  • JavaScript: โต้ตอบในหน้า โดยไม่ต้องโหลดใหม่
  • PHP + Laravel: routing, controller, Blade, validation
  • Eloquent ORM: ความสัมพันธ์ระหว่างตาราง
  • Authentication และการแบ่งสิทธิ์ผู้ใช้

users

  • name, student_id, email
  • role: student | admin
  • status: active | suspended

activities

  • user_id users
  • category_id categories
  • starts_at, ends_at, capacity
  • status, hidden_at

categories

  • name (unique)
  • ลบได้เมื่อไม่มีกิจกรรม

activity_participants

  • activity_id, user_id (unique)
  • status: pending · approved
  • · rejected · cancelled
  • attendance: present | absent

reviews

  • activity_id, user_id (unique)
  • rating 1–5, comment

reports

  • reporter_id users
  • target: activity | user
  • status, admin_note

moderation_logs

  • admin_id users
  • report_id reports
  • action, reason

notifications

  • notifiable users
  • data, read_at
