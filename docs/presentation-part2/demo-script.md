# ลำดับเดโม UniMate ส่วนที่ 2 (15 ต.ค. 2569)

ใช้คู่กับสไลด์หน้า 15 เดโมใช้เวลาประมาณ 6–7 นาที ลำดับนี้อิงข้อมูลตัวอย่างใน `database/database.sqlite` ที่ตรวจเมื่อ 10 ต.ค. 2569

## เตรียมก่อนขึ้นนำเสนอ

1. สำรองฐานข้อมูลก่อนเดโม เพราะเดโมจะเพิ่มคำขอ รีวิว รายงาน และโพสต์ใหม่

   ```powershell
   Copy-Item database\database.sqlite database\database.before-demo.sqlite
   ```

2. เปิดเว็บด้วย Herd (`http://unimate.test`) หรือ `php artisan serve` แล้วเปิดหน้า `/login` ล่วงหน้า 1 ครั้ง (ครั้งแรกอาจได้ 502 ให้รีโหลด)
3. เปิดเบราว์เซอร์ 2 หน้าต่าง: หน้าต่างปกติสำหรับนักศึกษา และหน้าต่างไม่ระบุตัวตนสำหรับ Admin
4. รหัสผ่านบัญชีทดสอบอยู่ใน `database/seeders/UserSeeder.php`
5. ตั้งซูมเบราว์เซอร์ 125–150% ให้คนหลังห้องอ่านออก

## ข้อควรระวัง

- ข้อมูลตัวอย่างมีวันที่คงที่ ณ 15 ต.ค. กิจกรรมที่ยังไม่เริ่มและขอเข้าร่วมได้คือ “TOEIC แบบกลุ่ม” (16 ต.ค.) และ “ทริปเชียงใหม่” (28 ต.ค.) ถ้าเลยวันแล้วให้ใช้โพสต์ที่สร้างในขั้น 3 ด้วยบัญชีอื่นแทน
- ขั้น 5 รีวิวได้เพราะ `student@` ถูกเช็กชื่อว่า “มา” ในกิจกรรมเดินป่าที่จบแล้ว และยังไม่เคยรีวิว รีวิวได้ครั้งเดียว ถ้าซ้อมไปแล้วให้กู้ฐานข้อมูลจากไฟล์สำรอง
- อย่าซ่อนกิจกรรมที่ต้องใช้ในขั้นก่อนหน้า ถ้าซ้อมแล้วกู้ข้อมูลคืนด้วย:

  ```powershell
  Copy-Item database\database.before-demo.sqlite database\database.sqlite -Force
  ```
